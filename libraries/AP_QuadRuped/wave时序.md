# 波浪步态运动时序

本文概述 `AP_QuadRuped_Wave` 当前实现的波浪步态时序（重心偏移暂未启用）。所有比率均针对单条腿在完整周期 `p∈[0,1)` 内的时间划分。

## 1. 周期分段

| 阶段       | 比例 (固定) | 说明 |
|------------|-------------|------|
| 抬腿摆动   | 0.25        | 单腿抬离地面，轨迹由摆线或贝塞尔生成。|
| 支撑推进   | 0.75        | 三腿支撑推进，落地腿保持线性回程。|

## 2. 单腿时间轴（示意）

```
0.00            0.50            1.00
│   抬腿  │              支撑              │
└────┬───┴──────────────────────────────┘
     ↑
   ≈0.25
```

- **抬腿摆动期 (`0 ≤ p < swing_ratio`)**
  - 相位固定 25%，路径可在摆线 (`generate_cycloid_trajectory`) 或贝塞尔 (`generate_bezier_trajectory`) 间切换，直接依据归一化时间生成曲线。
- **支撑推进期 (`p ≥ swing_ratio`)**
  - 摆线模式保持与摆动期对称，贝塞尔模式退化为线性插值，保证着地稳定。

## 3. 多腿相位关系

- 周期起点顺序：右前 (`RF`) → 左前 (`LF`) → 左后 (`LB`) → 右后 (`RB`)，相位间隔 `25%` 周期。
- 任意时刻仅有一条腿处于抬腿或准备后半段，其余三条腿提供支撑三角形。
- `refresh_phase_offsets()` 会在运行时监测 `gait_step_total` 变化并重新计算四条腿的起始步数，保证大步数场景下仍保持 25% 的相位错开。

## 4. 重心与姿态控制

- **重心偏移**：当前版本未启用（`calculate_support_polygon_centre_offset()` 返回零偏移）。
- **偏航命令 (`yaw_trajectory_generation`)**：
  - 准备前半阶段强制 0；准备后半段余弦缓入至峰值。
  - 抬腿阶段保持峰值；支撑阶段再线性回零，与重心回中同步。

## 5. 关键实现要点

1. 摆线与贝塞尔两种轨迹共用统一的归一化相位，方便调参也利于保持轨迹连续。
2. `refresh_phase_offsets()` 保证在运行时修改 `WAVE_STEP`（例如 80、100）时，相位起点与步长同步更新，避免“跳步”。

## 6. 调试建议

- 当前未启用重心偏移，可保持 `centre_offset_ratio=0`，后续若启用再按摩擦条件调整。
- 修改 `WAVE_STEP` 后无需重启，但可留意相位是否按预期排布（`refresh_phase_offsets()` 会自动更新）。
