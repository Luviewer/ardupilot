# 波浪步态运动时序

本文总结 `AP_QuadRuped_Wave` 在 2025-09-30 版本中的“先移重心再抬腿”波浪步态。所有比率均针对单条腿在完整周期 `p∈[0,1)` 内的时间划分。

## 1. 周期分段

| 阶段       | 基准比例 | 运行时范围 | 说明 |
|------------|----------|-----------|------|
| 重心准备   | 1/6 ≈ 0.167 | 0.12 – 0.22 | `get_phase_ratios()` 使用正弦微调，确保抬腿前重心已偏向支撑多边形。|
| 抬腿摆动   | 1/3 ≈ 0.333 | 0.30 – 0.36 | 同一函数以余弦调节，保证摆动相具有充足的腾空时间。|
| 支撑推进   | 余量        | 0.38 – 0.60 | 其余时间全部落在支撑阶段，为机体提供持续支撑与推进。|

- 分段总和通过归一化保持为 1。若支撑阶段缩短至下限，会按原始比例缩放准备与抬腿时长。
- `gait_lift_divisor = 3` 与基准 1/3 摆动相匹配，使 yaw 与高度控制的历史参数无需重新换算。

## 2. 单腿时间轴（示意）

```
0.00            0.50            1.00
│    准备    │      抬腿      │         支撑         │
└──────┬───┴──────────┬──────────────┘
       ↑              ↑
    ≈0.17          ≈0.50
```

- **重心准备期 (`0 ≤ p < prepare_end`)**
  - 足端保持着地，只允许 10% 余弦缓动的“微滑移” (`micro_blend`) ，用于吸收机体配重微调。
  - `calculate_support_polygon_centre_offset()` 用余弦曲线将 `centre_offset` 从 0 加速至目标偏移。
- **抬腿摆动期 (`prepare_end ≤ p < lift_end`)**
  - 路径可在摆线 (`generate_cycloid_trajectory`) 或贝塞尔 (`generate_bezier_trajectory`) 间切换。
  - `slow_phi()` 在摆动末段减速，确保落足速度接近 0。
- **支撑推进期 (`p ≥ lift_end`)**
  - 摆线模式保持与摆动期对称，贝塞尔模式退化为线性插值，保证着地稳定。
  - 重心在支撑期 60% 前保持偏移，最后 40% 余弦回中，为下一条腿预备。

## 3. 多腿相位关系

- 周期起点顺序：右前 (`RF`) → 左前 (`LF`) → 左后 (`LB`) → 右后 (`RB`)，相位间隔 `25%` 周期。
- 任意时刻仅有一条腿处于抬腿或准备后半段，其余三条腿提供支撑三角形。
- `get_phase_ratios()` 根据 `gait_step_leg_start[leg] / gait_step_total` 计算 `leg_phase_offset`，再以正弦/余弦调制各腿时序，使重心传递表现如波浪般平滑。

## 4. 重心与姿态控制

- **重心偏移**：
  - 准备阶段：余弦加速 (`0 → 1`)，保证抬腿前重心已落在支撑三角形内部。
  - 抬腿阶段：偏移权重保持 1，维持最大稳定裕度。
  - 支撑阶段：前 60% 保持 1，后 40% 余弦回中，避免突然回摆。
- **偏航命令 (`yaw_trajectory_generation`)**：
  - 准备前半阶段强制 0；准备后半段余弦缓入至峰值。
  - 抬腿阶段保持峰值；支撑阶段再线性回零，与重心回中同步。

## 5. 关键实现要点

1. `micro_blend` 的存在确保准备阶段仍为“着地”状态，防止移动重心时脚尖完全锁死导致扭矩过大。
2. 摆线与贝塞尔两种轨迹共用相同的阶段比例函数，保证速度规划一致，便于参数调试。
3. 各阶段的比例下限/上限可防止极端参数使机器人失去稳定支撑。

## 6. 调试建议

- 关注 `centre_offset_ratio` 与地面摩擦：摩擦较低时，可适度下调该参数或增大 `micro_blend` 系数。
- 若在 SITL/实机中发现某腿过早离地，可检查 `prepare_ratio` 调制系数（0.025）是否过大。
- 约束 `gait_step_total` 保持 24 的整周期，可获得最佳的相位均匀性；其他值需重新评估各腿相位偏移。
