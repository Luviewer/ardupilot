### ✅ 波浪步态重心移动整合 (2025-09-29)
### ✅ 波浪步态性能和稳定性优化 (2025-09-30)

#### 问题分析
- 原问题：波浪步态的重心移动与腿部轨迹生成是分离的，导致协调性不佳
- 核心需求：将重心移动完全整合到轨迹生成的步长中，形成统一的过程

#### 解决方案

##### 1. 重新设计轨迹生成时间分配
- **新的三阶段时间分配**：
  - 重心准备阶段：1/6周期 - 重心调整 + 腿部微调
  - 抬腿阶段：1/3周期 - 腿部离地运动 + 重心协调
  - 支撑阶段：1/2周期 - 地面推进 + 重心稳定

##### 2. 实现统一轨迹计算函数
- **正弦轨迹版本**：6个专门的计算函数
  - `calculate_centre_offset_wave()` - 重心偏移
  - `calculate_leg_adjustment_wave()` - 腿部调整
  - `calculate_centre_coordination_wave()` - 重心协调
  - `calculate_leg_lift_wave()` - 腿部抬升
  - `calculate_centre_stability_wave()` - 重心稳定
  - `calculate_leg_support_wave()` - 腿部支撑

- **贝塞尔曲线版本**：对应的6个贝塞尔曲线计算函数
  - 支持参数化调节：`bezier_control_height`和`bezier_control_forward`
  - 实现平滑的运动轨迹和精确的起止点控制

##### 3. 创新性改进：相位差别的重心移动策略
- **问题**：所有腿使用相同重心移动时间，造成不稳定性
- **解决方案**：根据每条腿的相位动态调整重心移动时间
```cpp
// 相位差别的重心移动策略
const float leg_phase_offset = (float)gait_step_leg_start[leg_index] / (float)gait_step_total;
const float centre_phase_offset = leg_phase_offset * 0.25f;

// 动态时间分配
const float prepare_ratio = 0.167f + 0.033f * sinf(centre_phase_offset * M_2PI);
const float lift_ratio = 0.333f + 0.025f * cosf(centre_phase_offset * M_2PI);
const float support_ratio = 1.0f - prepare_ratio - lift_ratio;
```

#### 技术特点
1. **完全整合**：重心移动成为轨迹生成的有机组成部分
2. **波浪式传递**：重心像波浪一样在四条腿间传递
3. **双重轨迹支持**：正弦轨迹 + 贝塞尔曲线轨迹
4. **参数化控制**：通过参数可实时调节轨迹特性
5. **运动平滑**：使用`slow_phi`函数实现末端减速

### ✅ 波浪步态性能和稳定性优化 (2025-09-30)

#### 完成的优化项目

##### 1. 重心移动参数优化
- **调整振幅系数**：将时间分配振幅从0.033/0.025减小到0.025/0.020
- **优化贝塞尔控制点**：高度系数从0.3调整到0.25，前向系数从0.2调整到0.15
- **效果**：提高运动稳定性，减少过冲，增强步态协调性

##### 2. 重心移动边界检查
- **安全边界**：X/Y轴±50mm，Z轴±10mm硬限制
- **软限制机制**：X/Y轴±40mm，Z轴±8mm比例缩放软限制
- **安全函数**：`apply_centre_offset_limits()`和`is_centre_offset_safe()`
- **效果**：防止机械结构过载，提高系统安全性

##### 3. 三角函数计算性能优化
- **相位缓存机制**：为每条腿实现独立的sin/cos值缓存
- **智能缓存策略**：10ms超时+0.001角度精度的缓存有效性检查
- **缓存函数**：`get_cached_sin()`和`get_cached_cos()`
- **效果**：减少重复计算，提高实时性能

##### 4. 平滑重心传递增强
- **自适应平滑滤波**：根据变化幅度动态调整平滑因子
- **趋势预测**：基于历史速度预测未来重心位置
- **平滑传递函数**：`calculate_smooth_centre_transfer()`
- **效果**：实现更自然、更流畅的重心传递过程
